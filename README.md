# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior using Python, SQL, and Power BI. The objective is to understand customer purchasing patterns, identify sales trends, analyze customer preferences, and generate meaningful business insights from retail transaction data.

The project follows an end-to-end data analytics workflow, starting with data cleaning and exploratory data analysis in Python, followed by SQL-based analysis in MySQL and interactive dashboard development in Power BI.

## Tools & Technologies

- **Python:** Pandas
- **Database:** MySQL
- **Data Visualization:** Power BI
- **Development Environment:** VS Code
- **Version Control:** Git & GitHub

## Project Workflow

### 1. Data Cleaning & Exploratory Data Analysis (Python)

- Imported the customer shopping behavior dataset using Pandas.
- Performed initial data inspection using `head()`, `info()`, and `describe()`.
- Identified and handled missing values.
- Filled missing review ratings using category-wise median values.
- Standardized column names for consistency.
- Created new features such as age groups.
- Performed exploratory data analysis to understand customer purchasing patterns.

### 2. Data Analysis (MySQL)

- Created a MySQL database named `customer_behavior`.
- Imported the cleaned dataset into MySQL.
- Used SQL queries to analyze customer purchasing behavior.
- Applied aggregate functions such as COUNT, SUM, AVG, and GROUP BY.
- Analyzed customer segments, product categories, purchase patterns, and other business metrics.

### 3. Dashboard Development (Power BI)

- Connected MySQL database to Power BI.
- Imported the customer dataset.
- Created DAX measures for calculating key business metrics.
- Designed an interactive Customer Shopping Behavior Dashboard.
- Used visualizations to present customer trends and purchasing insights.
